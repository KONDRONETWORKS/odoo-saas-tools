Website Sale Require Login
===========================

Ce module force les utilisateurs à se connecter avant d'accéder au site de vente en ligne.

**Fonctionnalités:**
- Redirige les utilisateurs anonymes vers la page de connexion lorsqu'ils accèdent au shop
- Configuration via Paramètres > Site Web
- Protection des pages produit et catégorie

**Installation:**
1. Installer le module
2. Activer l'option dans Paramètres > Site Web > "Require Login for Shop"

**Compatibilité:**
- Odoo 18.0
