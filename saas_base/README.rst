SaaS Base
=========

Module de base commun pour tous les modules SaaS.

**Description:**
Ce module fournit les classes de base, utilitaires et exceptions communes utilisées par tous les modules SaaS.

**Dépendances:**
- base

**Fichiers principaux:**
- models/saas_base.py : Modèles de base pour SaaS
- tools.py : Fonctions utilitaires communes
- exceptions.py : Exceptions personnalisées

**Utilisé par:**
- saas_portal
- saas_server
- saas_client

**Fonctionnalités:**
- Classes de base réutilisables
- Outils de manipulation de bases de données
- Gestion des exceptions SaaS
