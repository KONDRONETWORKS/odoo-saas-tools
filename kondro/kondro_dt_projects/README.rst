Kondro DT Projects
==================

Extension des projets pour le Directeur Technique : jalons, risques et
bibliothèque technique directement reliés aux dossiers commerciaux.

Fonctionnalités
---------------

* Champs supplémentaires sur les projets (phase technique, date limite, synthèse).
* Suivi des jalons techniques avec planification et progression.
* Gestion des risques (probabilité/impact, plan d’atténuation, revue).
* Référentiel HLD/LLD et documents techniques avec pièces jointes ou liens.
* Boutons rapides et onglet « Technique » dans le formulaire projet.

Installation
------------

1. Installer ``kondro_dt_hub``.
2. Installer ``kondro_dt_projects`` depuis les Apps.
3. Donner les droits adéquats (Utilisateur / Manager / Administrateur DT).

Les vues et actions sont accessibles via le menu Directeur Technique et depuis
les projets KONDRO.
