KONDRONETWORKS - Configuration Entreprise
==========================================

Module de configuration spécifique pour KONDRONETWORKS en Côte d'Ivoire.

Fonctionnalités
----------------

* Configuration automatique de l'entreprise KONDRONETWORKS
* Paramètres de localisation Côte d'Ivoire (XOF, langue française)
* Configuration fiscale et légale ivoirienne
* Données de base de l'entreprise
* Paramètres par défaut pour les modules KONDRO

Informations Entreprise
-----------------------

* **Nom** : KONDRONETWORKS
* **Pays** : Côte d'Ivoire
* **Devise** : XOF (Franc CFA Ouest-Africain)
* **Langue** : Français
* **Fuseau horaire** : Africa/Abidjan
* **Email** : contact@kondronetworks.com
* **Site web** : https://www.kondronetworks.com
* **Ville** : Abidjan

Installation
------------

1. Assurez-vous que ce module est placé dans le ``addons_path`` de votre installation Odoo
2. Redémarrez votre serveur Odoo
3. Accédez à la section "Apps" (Applications) dans Odoo
4. Recherchez "KONDRONETWORKS - Configuration Entreprise" ou "kondro_company"
5. Cliquez sur le bouton "Installer"

Dépendances
-----------

* base
* base_setup

Utilisation
-----------

Après l'installation, l'entreprise "KONDRONETWORKS" sera configurée avec les paramètres spécifiés. Vous pouvez vérifier et modifier ces informations via :

``Paramètres > Utilisateurs & Sociétés > Sociétés``

Les nouveaux utilisateurs auront ``Africa/Abidjan`` comme fuseau horaire par défaut.

Note
----

Ce module doit être installé en premier pour configurer correctement l'environnement KONDRONETWORKS.
