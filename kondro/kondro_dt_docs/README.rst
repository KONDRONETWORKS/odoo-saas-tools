Kondro DT Docs
==============

Bibliothèque collaborative du Directeur Technique centralisant modèles,
artefacts et documents opérationnels.

Fonctionnalités
---------------

* Catégories et tags pour classer HLD, LLD, procès-verbaux, scripts, etc.
* Workflow documentaire simple (brouillon → revue → validation → archivage).
* Référencement automatique (séquence configurable) et suivi des versions.
* Liaison directe avec projets, dossiers commerciaux, artefacts techniques et
  dépenses.
* Intégration aux vues projet/dossier avec compteurs et onglets dédiés.
* Notifications mail/activity pour responsables, relecteurs et validateurs.

Installation
------------

1. Installer ``kondro_dt_projects`` et ``kondro_dt_workflow``.
2. Installer ``kondro_dt_docs`` depuis les Apps.
3. Configurer les catégories initiales (menu Directeur Technique → Bibliothèque).

Les documents validés deviennent en lecture seule et alimentent la gouvernance
DT via le hub et les modules associés.
