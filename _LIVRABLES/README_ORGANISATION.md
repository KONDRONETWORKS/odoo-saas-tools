# 📁 Organisation des Livrables

## 📂 Structure des Dossiers

### `/documentation/` - Documentation Technique

Contient tous les documents de documentation technique :
- **Analyses** : `ANALYSE_*.md`
- **Bilans** : `BILAN_*.md`
- **Corrections** : `CORRECTIONS_*.md`
- **Guides** : `GUIDE_*.md`
- **Migrations** : `MIGRATION_*.md`
- **Optimisations** : `OPTIMISATIONS_*.md`
- **Rapports** : `RAPPORT_*.md`
- **Résumés** : `RESUME_*.md`
- **Tests** : `TEST_*.md`

### `/scripts/` - Scripts Utilitaires

Contient tous les scripts Python et Shell :
- **Scripts de correction** : `fix_*.py`, `fix_*.sh`
- **Scripts de vérification** : `check_*.py`
- **Scripts de maintenance** : `rename_*.py`, `update_*.sh`, etc.

### `/solutions/` - Solutions Spécifiques

Contient les guides de solutions pour problèmes spécifiques :
- **Configuration OAuth** : `CONFIGURATION_OAUTH.md`
- **Guides rapides** : `GUIDE_CONFIGURATION_OAUTH_RAPIDE.md`

### `/scripts_migration/` - Scripts de Migration

Contient les scripts utilisés pour la migration vers Odoo 18.

---

## 📄 Fichiers à la Racine de `_LIVRABLES/`

- **`INDEX.md`** : Index principal de toute la documentation
- **`README.md`** : Documentation générale du projet
- **`test-unitaire.txt`** : Résultats des tests unitaires
