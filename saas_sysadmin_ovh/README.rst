SaaS Sysadmin OVH
=================

Configuration des paramètres OVH depuis *Paramètres ▸ SaaS Server* :

- Application Key / Secret / Consumer Key
- Endpoint OVH (ovh-eu, ovh-ca, …)
- Domaine racine pour les sous-domaines clients

Ces informations seront utilisées par les scripts d'automatisation pour créer les entrées DNS côté OVH lors du provisioning d'une instance SaaS.
